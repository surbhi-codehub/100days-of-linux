# Title: Viewing the Begining of Files with head
---
## 1. Create a file named fruis .txt with at least 10 lines of txt, then display the first 10 lines using head.
*Ans*
```base
head fruits.txt
```
---
## 2. Display only the first 5 lines of fruits.txt.
*Ans*
```base
head -n 3 employees.txt
```
---
## 3. Create a file named employees.txt with at least 8 lines and display the first 3 lines.
*Ans*
```base
head -n 3 employees.txt
```
## 4. Navigate to another directory and use head to view the beginning of a text file there.
*Ans*
```base
cd && head filename
```
