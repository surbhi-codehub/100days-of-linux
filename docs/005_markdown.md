# Title: Moving and Renaming Files with mv
---
## 1. Create a file named notes.txt and rename it to notes_day8.txt.
### Ans touch notes.txt && mv notes.txt notes_day8.txt
---
## 2.Create a directory named backup and move notes_day8.txt into it.
### Ans mkdir backup && mv notes_day8.txt backup/
---
## 3. List the content of the backup directory to veriy the move.
### Ans ls backup
---
## 4. Create a directory named projects and rename it to linux_projects.
### Ans mkdir projects && mv projects linux_projects
---
## 5. Display your current working directroy.
### Ans pwd
