# Title: Revision Quiz #2 -File Viewing & Editing
---
##1. Create a file named review.txt using nano. Write at least 12 lines, save it, and exit.
```
Ans nano review .txt(Ctrl+O, Enter, Ctrl+X)
```
---
##2. Display the entire contents of review.txt using cat.
```
Ans cat review.txt
```
---
##3. Display the first 5 lines and the last 5 lines of review.txt.
```
Ans head -n 5 review.txt && tail -n 5 review.txt
```
---
##4. Open review.txt with less, search for a word, then quit. Next open it with more and move to next page before quitting.
```
Ans less review.txt(/, q) then more review.txt (Space, q)
```
