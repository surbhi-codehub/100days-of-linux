# Title: Reading Large Files with less.
---
## 1. Create a file named notes.txt with at least 25 lines and open it using less.
### Ans
```basic
less notes.txt
```
---
## 2. Inside less, move to the next page and then retrun to the previous page.
### Ans 
```base
Press Space, then b
```
---
## 3. Search for a word  that appeara in your file using the search  feature.
### Ans
```base
Press / followed by the search text and Enter
```
---
## 4. Exit less using the correct keyboard key.
### Ans
```base
press q
```
---
## 5. Display your current working directory after finishing the exercise.
### Ans
```base
pwd
```
