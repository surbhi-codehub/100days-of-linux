# Title: Editing Files with nano.
---
## 1. Create a file named notes.txt using nano and write five lines about yourself. Save the file a Nano.
### Ans 
```base
nano notes.txt
```
## 2.  Open notes.txt again and add two more lines. Save the changes and exit.
### Ans
```base
nano notes.txt(edit and save)
```
## 3. Search for a word inside notes.txt using Nano's search shortcut.
### Ans 
```
ctrl+W....Nano
```
## 4. Create a file named commands.txt and write the Linux commands you learned 16.
### Ans
```
nano commands.txt
```
## 5. Display the cotents of commands.txt using the cat command after exiting Nano.
### Ans
```
pwd
```
