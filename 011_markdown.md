# Title: Reading Files with cat.
---
## 1. Create a file named welcome.txt and add the text 'Welcome to Linux' using any method you know, then display it with cat.
**Ans**
```base
cat welcome.txt
```
___
## 2. Create two files named python.txt and sql.txt, addd one line of text to each, then display both files using a single cat command.
**Ans**
```base
cat python.txt sql.txt
```
___
## 3. Display the contents of README.md from your practice folder.
**Ans**
```
cat README.md
```
___
## 4. Navigate to a different directory and use cat to display a text file stored there.
**Ans**
```base
cd && cat filename
```
___
## 5. Display your current working directory after completing the tasks.
**Ans**
```base
pwd
```
